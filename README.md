# YouTube Summariser and Evaluator

A web app where user can paste a YouTube link and get an AI generated 5 point summary and a quiz based on the video content.

## How it works

1. User pastes a YouTube URL
2. Backend extracts the video transcript using YouTube Transcript API
3. Transcript is sent to Google Gemini AI
4. Gemini generates a 5 point summary and 3 quiz questions
5. Results are displayed on the webpage

## Tech Stack

- **Backend** — Python, Flask
- **AI** — Google Gemini 2.5 Flash
- **Transcript** — youtube-transcript-api
- **Frontend** — HTML, CSS, JavaScript

## Setup Instructions

### 1. Clone the repository
### 2. Install dependencies
### 3. Get a Gemini API key
### 4. Run the app
### 5. Open in browser
Go to `http://127.0.0.1:5000`
